# Wikipedia Search Application

A modern Wikipedia search application built using HTML, CSS, and JavaScript.  
This application fetches real-time search results using the Fetch API and displays them dynamically.

## 🔗 Live Demo
https://itsvanke.github.io/wikipedia-search-application/

## 🛠 Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap
- Fetch API

## ✨ Features
- Debounced search functionality
- Dynamic result rendering
- Loading spinner
- Error handling
- Responsive design
